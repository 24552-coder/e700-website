# 雙和醫院病歷組 - 公文 Google 郵件自動發送與進度追蹤系統

## 📌 簡介
本專案為雙和醫院病歷組量身打造之公文與醫師函詢管理系統，徹底整合 Google Workspace (Gmail / Google Drive)，免除 Office 365 授權成本。

## 📁 檔案結構 (位於 `D:\峻弦_BI\ai\病歷0907`)
```
D:\峻弦_BI\ai\病歷0907\
├── index.html               # 系統主畫面 UI (網頁介面)
├── styles.css               # Vanilla CSS 樣式系統 (高質感醫療 BI 主題)
├── app.js                   # 核心前端與資料邏輯 (進度計算/大檔轉雲端/郵件引擎/週表匯出)
├── server.py                # Python 本地 Web 伺服器 & API 服務
├── google_apps_script.js    # 部署至 Google Workspace 之 Apps Script 腳本
├── 系統計畫書.md            # 完整架構規劃與資料庫欄位設計計畫書
└── README.md                # 本說明文件
```

## 🚀 啟動與使用步驟

### 方法一：開啟獨立網頁 (快速檢視與測試)
1. 雙擊開啟 `index.html`，即可直接在瀏覽器中使用完整功能。
2. 可點選「新增公文主檔」、「新增醫師函詢問題」、「自動發送 Google 郵件」、「退回補件」、「模擬醫師點信回覆」及「匯出未結案週表」。

### 方法二：透過 Python 伺服器運行
1. 開啟終端機 (Terminal) 或 Command Prompt：
   ```bash
   cd D:\峻弦_BI\ai\病歷0907
   python server.py
   ```
2. 開啟瀏覽器訪問 `http://localhost:8080` 即可使用。

## 🌟 核心功能一覽
1. **公文主檔 20 欄位與進度自動計算**：自動計算函詢狀態顯示如 `4/5 (80%)` 或 `不需醫師已完成`。
2. **Google 郵件雙向收發**：發送函詢信件給醫師並自動抄送 (Cc) 承辦與副本信箱；醫師直接點擊 Gmail 回覆即可自動寫入狀態為 `已回覆`。
3. **退回補件與強制原因**：具備「退回補件」按鈕與退回原因強制對話框，自動觸發紅色警示通知信。
4. **超大附件轉雲端 (>10MB / 25MB)**：自動判別附件大小，超過門檻自動轉換為 Google Drive 安全下載連結。
5. **逾期催辦與警示看板**：每日掃描未回覆超過 1 天之案件，自動寄發催辦信與儀表板紅字警示。
6. **未結案週表匯出**：一鍵匯出符合標準規格之 Excel 週表檔名 `雙和醫院病歷組_公文函詢週表_YYYYMMDD.xlsx`。
